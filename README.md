# Hot Pursuit
Evade the floating skulls and walls of fire for as long as you can.  
Your companion Cecil may be able to help.

![Sample recording of game](./hot-pursuit.gif)

## Controls
- **D-pad** - Move player

# Play
## Online (recommended)
Visit https://uglybrecke.github.io/hot-pursuit

## Build from source
First, either open the project in the included VSCode Dev Container or install Butano and its dependencies.
If you use the latter option, set the `LIBBUTANO` `Makefile` variable to the path Butano is installed at.
Once finished, run `make`.
Then open `hot-pursuit.gba` in your emulator. (or copy to a flash cart!)
